# Event Hub – Software Testing & Bug Reporting
Manual testing of the Event Hub web application covering Admin, Registered User, and Guest User roles. Includes requirement-based testing, a bug report documenting 50+ identified defects, and a test summary report.

Tested the Event Hub Web Application, which includes three user roles: Admin, Registered User, and Guest User.

Performed manual testing based on the provided requirements to verify application functionality, role-based access control, user workflows, and overall system behavior.

Testing Activities
Conducted requirement-based manual testing.
Tested Admin, Registered User, and Guest User functionalities.
Identified and documented 50+ bugs during the testing process.
Created a detailed bug report sheet with defect descriptions and relevant information.
Prepared a test summary report outlining the testing activities and identified issues.
Verified application behavior against the expected results defined in the requirements.
Project Deliverables
Bug Report Sheet: Detailed documentation of identified defects.
Test Summary Report: Overview of testing activities and results.
Requirement-Based Testing: Validation of application functionality against requirements.
Objective

To identify functional defects, usability issues, and potential access-control problems, helping improve the quality, reliability, and user experience of the Event Hub Web Application.
